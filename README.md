# Terraza_del_pri_Restaurante
Esta es una aplicación web moderna desarrollada con React (frontend) y Django (backend) que simula el sistema de pedidos y menú de un restaurante llamado "Terraza del Pri". El objetivo es ofrecer una experiencia visual atractiva y funcional para la gestión de menús, pedidos a domicilio y visualización de platos.

🚀 Características principales:
Interfaz amigable con diseño oscuro en negro y amarillo para mayor contraste visual.

Menú interactivo con subcategorías dinámicas (Hamburguesas, Salchipapas, Perros calientes).

Formulario de pedidos a domicilio con campos para nombre, dirección, teléfono y detalles del pedido.

Backend construido con Django REST Framework para facilitar futuras integraciones con bases de datos y APIs.

Preparado para despliegue en producción mediante el uso de npm run build y conexión con Django como servidor backend.

🛠️ Tecnologías utilizadas:
Frontend: React, Bootstrap

Backend: Django, Django REST Framework

Otros: HTML5, CSS3, JavaScript, Python
